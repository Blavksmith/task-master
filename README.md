# TaskMaster

**TaskMaster** adalah aplikasi manajemen tugas berbasis web yang dirancang untuk membantu individu dan tim mengelola tugas serta proyek secara terstruktur dan kolaboratif.  
Dengan antarmuka yang intuitif dan fitur-fitur fleksibel, TaskMaster bertujuan untuk:

- Meningkatkan efisiensi kerja  
- Mengurangi miskomunikasi  
- Mendukung transformasi digital di berbagai sektor seperti pendidikan, komunitas, UMKM, dan startup  

---

## Fitur Utama

- **Pembuatan dan Pengelolaan Tugas**  
  Tambah, edit, hapus, dan selesaikan tugas sesuai kebutuhan tim atau individu.  

- **Manajemen Tim**  
  Tambah anggota tim, atur peran, dan kelola hak akses.  

- **Pelacakan Progres Tugas**  
  Pantau perkembangan tugas secara real-time oleh seluruh anggota tim.  

- **Antarmuka Pengguna Intuitif**  
  Dirancang untuk kemudahan penggunaan tanpa pelatihan teknis.  

- **Dashboard Interaktif**  
  Visualisasi tugas dan tenggat waktu untuk organisasi yang lebih baik.  

- **Sistem Tag dan Prioritas**  
  Kelompokkan tugas dan fokus pada pekerjaan yang lebih penting.  

---

## Manfaat

- **Efisiensi Kerja**: Tingkatkan efektivitas tim dengan sistem manajemen tugas yang terstruktur.  
- **Mengurangi Miskomunikasi**: Minimalkan konflik akibat pembagian tugas yang tidak jelas.  
- **Dokumentasi Kerja**: Sediakan catatan yang dapat dipantau, dievaluasi, dan diarsipkan.  
- **Transformasi Digital**: Dukung budaya kerja modern dengan alat kolaboratif untuk koordinasi tim.  
- **Pengalaman Pengembangan**: Berikan mahasiswa pengembang kesempatan menerapkan keterampilan teknologi dalam konteks nyata.  

---

## Teknologi yang Digunakan

TaskMaster dibangun dengan teknologi modern untuk performa dan skalabilitas:

| **Kategori** | **Teknologi** |
|--------------|---------------|
| Front-end    | Next.js, TypeScript, Tailwind CSS, Shadcn/UI, Framer Motion |
| Back-end     | Supabase, Supabase Auth, PostgreSQL |
| Hosting      | Vercel (Front-end), Supabase (Back-end & Database) |

> **Catatan**: Semua teknologi bersifat open-source atau gratis, memastikan efisiensi biaya.

## Instalasi

### Prerequisite
- Node.js (versi 18 atau lebih baru)  
- Akun Vercel (untuk hosting front-end)  
- Akun Supabase (untuk hosting back-end dan database)  

### Langkah-langkah

1. Clone repositori:
   ```bash
   git clone <URL_REPOSITORI>

2. Masuk ke direktori proyek:

   ```bash
   cd taskmaster
   ```

3. Install dependensi:

   ```bash
   npm install
   ```

4. Konfigurasi variabel lingkungan:

   ```bash
   cp .env.example .env.local
   ```

   Edit file `.env.local` dengan kredensial Supabase dan konfigurasi lainnya.

5. Jalankan aplikasi secara lokal:

   ```bash
   npm run dev
   ```

---

## Deploy Aplikasi

1. Push kode ke repositori GitHub.
2. Hubungkan repositori ke **Vercel** untuk deploy front-end.
3. Konfigurasi back-end dan database di **Supabase**.

## Pengembangan

Proyek TaskMaster dikembangkan menggunakan pendekatan **Software Development Life Cycle (SDLC)** dengan model **Scrum**:

1. **Analisis Kebutuhan**
   Mengumpulkan data dari pengguna (pelajar, pekerja jarak jauh, komunitas) untuk menentukan fitur utama.

2. **Perancangan Sistem**
   Membuat mockup UI/UX dan arsitektur teknis untuk front-end dan back-end.

3. **Implementasi**
   Pengembangan front-end (Next.js) dan back-end (Supabase, PostgreSQL) secara paralel.

4. **Pengujian**
   Melakukan pengujian unit, integrasi, dan beta testing dengan pengguna.

5. **Evaluasi dan Finalisasi**
   Memperbaiki bug berdasarkan umpan balik dan menyelesaikan dokumentasi.
